# KINGS ONLY — PRODUCT.md

## Mission

KINGS ONLY is the digital headquarters of a competitive Free Fire guild. It is where the guild's identity, progression, and history live — the place members enter to find their squad, check their rank, and see the guild move together.

## Audience

- **Members** — mostly on mobile phones, between scrims. They want their stats, the leaderboard, the next event, and their squad — fast.
- **Leadership** — on desktop, running the guild: approving join requests, creating events and challenges, managing teams, and watching sync health.

## Brand voice

Confident, competitive, and direct. No hype-speak, no gamer slang in the UI. Copy is short, concrete, and commands respect: "PLAY TOGETHER. COMPETE AS ONE."

## UX goals

1. The guild is the hero. Every screen reinforces "this is our guild."
2. Mobile is the primary product. Desktop is the command center.
3. Statistics are the language of the platform — numbers lead, labels follow.
4. The feed is alive: activity, challenges, and events make the guild feel inhabited.
5. Demo data is always labeled — the platform never pretends mock data is live.

## User journeys

- **New member**: register → request to join → profile completion (link FF UID, pick role/region) → sync → dashboard shows personal performance + guild status.
- **Active member**: open app → check notification badge → see active challenge progress → join event → find squad → post match result.
- **Admin**: approve join requests → create weekly challenge → schedule event → trigger player sync → moderate posts → view analytics.

## Feature priorities

1. Guild dashboard, player profiles, leaderboards — the core loop.
2. Events, challenges, achievements — the progression loop.
3. Teams, tournaments, squad finder — the competitive loop.
4. Community, notifications, announcements — the social loop.
5. Admin + sync — the operations loop.

## Non-goals (v1)

- No external Free Fire scraping, credential collection, or anything violating Garena's terms.
- No real-money transactions.
- No matchmaking outside the guild.
- No mobile apps beyond the web app.
